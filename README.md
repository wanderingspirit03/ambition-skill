# ambition

A Claude Code skill that rewrites a task into a more ambitious version using the altitude, depth and range method from Felix Rieseberg's essay [How to be more ambitious: a tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/).

It shows the rewrite as a short brief and waits for you to choose before doing any of the work.

## Install

```bash
git clone https://github.com/wanderingspirit03/ambition-skill ~/.claude/skills/ambition
```

Then ask for it with `/ambition` or "make this more ambitious".

## Files

- `SKILL.md`: the skill itself.
- `references/essay-notes.md`: a short summary of the essay and its worked examples.
